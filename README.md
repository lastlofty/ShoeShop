# ShoeShop — магазин обуви «Топотун»

Учебный проект по подготовке к демонстрационному экзамену (КОД 09.02.07-2-2026):
информационная система магазина обуви — база данных MySQL и настольное приложение для каталога, остатков и заказов.

**Команда:** ФИО, группа — впишите
**Стек:** MySQL 8.0 · MySQL Workbench · C# / WPF (.NET 8) · draw.io · Git/GitHub

## Быстрый старт БД

В MySQL Workbench по очереди открыть (**File → Open SQL Script**) и выполнить:
`db/create_v1.sql` → `db/insert_data.sql` → `db/checks.sql`.

Из консоли:

```bat
mysql -u root -p < db\create_v1.sql
mysql -u root -p < db\insert_data.sql
```

Отчёт по проекту (`Отчёт.docx`) ведётся отдельно и в репозиторий не добавляется.
