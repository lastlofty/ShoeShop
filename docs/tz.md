# Техническое задание v1 — ShoeShop

> Версия 1 (пары 5–6). Основа — задание демонстрационного экзамена КОД 09.02.07-2-2026, модули 1–3.

## 1. Назначение

Система автоматизирует работу магазина обуви «Топотун»: хранит каталог товаров с актуальными остатками, учётные записи пользователей с ролями и заказы с пунктами выдачи.

## 2. Состав системы

| Компонент | Технология | Где лежит |
|---|---|---|
| База данных | MySQL 8.0, схема `topotun`, 10 таблиц, 3НФ | `db/` |
| Приложение | C# / WPF, .NET 8, EF Core (Pomelo MySQL) | `src/` (с занятия 5) |
| Документация | Markdown, PNG, draw.io | `docs/` |

## 4. Требования к базе данных

- 3-я нормальная форма, ссылочная целостность (PK/FK), согласованные имена в `snake_case`.
- ER-диаграмма в PDF (`docs/diagrams/erd.pdf`), скрипт создания (`db/create_v1.sql`).
- Данные заказчика загружены полностью и без искажений.

## 5. Нефункциональные требования

- Единый стиль окон по руководству (Приложение 3 ДЭ), логотип и иконка приложения.
- Именование: PascalCase — классы, методы, свойства; camelCase — локальные переменные; одна команда в строке.
- Комментарии только в неочевидных местах.
- Приложение не завершается аварийно ни в одном сценарии; скриншоты отладки — в отдельном docx.
